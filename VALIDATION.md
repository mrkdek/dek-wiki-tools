# Проверка комплекта

Дата: 23 ноября 2026 года. Проверено локально в Chrome по HTTP, сайт размещался в подпапке `/dek-wiki-tools/`, аналогичной адресу проекта GitHub Pages.

- Обойдены 30 статей оглавления Teletype; найдены 3 iframe, дополнительных ссылок на статьи вне оглавления нет.
- Извлечены полные srcdoc/data URL; SHA-256 трёх файлов в `originals/` совпадают с извлечённым кодом.
- Проверен синтаксис 8 JavaScript-блоков и файлов; ошибок нет. Все локальные ссылки на JS/CSS существуют.
- Проверены все 8 прямых маршрутов рабочих инструментов: нужный заголовок виден, меню в режиме отдельного embed скрыто, ошибок JavaScript нет.
- Форма настройки: изменено имя компьютера, отключены Illustrator и принтер; тема и описание корректно обновились.
- Everything: список с повторяющимися артикулами преобразован в `123456 | 987654`.
- Конвертер: загружен специально созданный PNG 640×480; скачан JPG 500×375.
- Служебная записка: заполнены тестовые данные; сформирована тема письма, скачан PNG A4 2480×3508.
- Все 3 приложения загружены в iframe с другого origin (`localhost` → `127.0.0.1`), с sandbox-параметрами из генератора. Проверено изменение полей и формирование результатов; ошибок JavaScript нет.
- Проверена кнопка копирования embed-ссылки: интерфейс подтвердил успешное копирование.

Внешняя проверка орфографии Яндекс Спеллер не тестировалась отправкой пользовательских документов. Не выполнялись исчерпывающие проверки всех форматов файлов и больших/повреждённых архивов: сохранены исходные возможности и ограничения инструментов.

Публикация в GitHub и вставка в действующую wiki не выполнялись — запрошены только папка и ZIP. Совместимость произвольного GitHub Pages URL с Embed вашей версии Outline нужно проверить после публикации; инструкции и требования к разрешениям iframe приведены в README.
